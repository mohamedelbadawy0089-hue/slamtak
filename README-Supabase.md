# دليل ربط المساعد الذكي بقاعدة بيانات Supabase

## 📋 نظرة عامة

تم ربط المساعد الذكي بقاعدة بيانات Supabase لحفظ واسترجاع بيانات المنتجات بشكل آمن ومؤمن.

## 🔧 الإعداد

### 1. إنشاء مشروع Supabase

1. اذهب إلى [supabase.com](https://supabase.com)
2. قم بإنشاء حساب جديد أو تسجيل الدخول
3. أنشئ مشروع جديد
4. انتظر حتى يتم تجهيز المشروع

### 2. الحصول على بيانات الاتصال

1. من لوحة تحكم المشروع، اذهب إلى **Settings > API**
2. انسخ **Project URL** و **anon public key**
3. استبدل القيم في ملف `supabase-config.js`:

```javascript
this.supabaseUrl = 'https://YOUR_PROJECT_ID.supabase.co';
this.supabaseKey = 'YOUR_SUPABASE_ANON_KEY';
```

### 3. إنشاء الجداول

1. اذهب إلى **SQL Editor** في لوحة تحكم Supabase
2. انسخ وألصق محتوى ملف `supabase-schema.sql`
3. اضغط **Run** لتنفيذ الأوامر

## 🚀 الاستخدام

### في صفحة الإدخال الجماعي

1. افتح `bulk-add-products.html`
2. أدخل بيانات المنتجات في الجدول
3. اضغط على زر **"💾 حفظ في قاعدة البيانات"**
4. سيتم حفظ جميع البيانات تلقائياً

### في المساعد الذكي

1. افتح المساعد الذكي
2. اضغط على زر **"🗄️"** في رأس المساعد
3. سيتم الاتصال بقاعدة البيانات وعرض الإحصائيات

## 📊 الميزات المتاحة

### 💾 حفظ البيانات
- حفظ المنتجات من الجدول مباشرة
- التحقق من صحة البيانات قبل الحفظ
- إشعارات النجاح والفشل

### 📋 استرجاع البيانات
- عرض جميع المنتجات
- البحث عن منتجات محددة
- الحصول على إحصائيات المخزون

### 🔍 البحث المتقدم
- بحث بالاسم
- بحث بالباركود
- بحث بالفئة

### 📈 الإحصائيات
- إجمالي عدد المنتجات
- القيمة الإجمالية للمخزون
- متوسط الأسعار
- المنتجات منخفضة المخزون

## 🛡️ الأمان

### Row Level Security (RLS)
- تم تفعيل سياسات الأمان على جميع الجداول
- المستخدمون يمكنهم الوصول إلى بياناتهم فقط
- حماية البيانات من الوصول غير المصرح به

### السياسات المطبقة
- **المنتجات**: القراءة والإضافة والتحديث والحذف
- **المبيعات**: القراءة والإضافة والتحديث
- **المشتريات**: القراءة والإضافة والتحديث
- **المخزون**: القراءة والتحديث

## 📱 الأزرار المتاحة

### في لوحة المساعد
```
📋 نسخ البيانات    - نسخ بيانات الجدول
📁 اختيار ملف      - استيراد من ملف
🗄️ قاعدة البيانات  - الاتصال والإحصائيات
❌ إغلاق           - إغلاق المساعد
```

### في صفحة الإدخال الجماعي
```
➕ إضافة صف جديد           - إضافة صف جديد للجدول
🤖 اختبار المساعد         - اختبار وظائف المساعد
🤖 إدخال جماعي تلقائي     - إدخال تلقائي للبيانات
💾 حفظ في قاعدة البيانات  - حفظ البيانات في Supabase
```

## 🔧 وظائف JavaScript

### الاتصال بقاعدة البيانات
```javascript
// تهيئة الاتصال
await window.SupabaseManager.init();

// حفظ المنتجات
await window.SupabaseManager.saveProducts(products);

// استرجاع المنتجات
const products = await window.SupabaseManager.getProducts();

// البحث عن المنتجات
const results = await window.SupabaseManager.searchProducts('باراسيتامول');

// الحصول على إحصائيات
const stats = await window.SupabaseManager.getStatistics();
```

## 📝 مثال الاستخدام

```javascript
// حفظ منتج جديد
const newProduct = {
    name: 'باراسيتامول 500مجم',
    price: 15.50,
    quantity: 100,
    discount: 5,
    barcode: '1234567890123',
    expiry_month: 12,
    expiry_year: 2025,
    category: 'أدوية'
};

await window.SupabaseManager.saveProducts([newProduct]);
```

## 🚨 معالجة الأخطاء

### أخطاء الاتصال
- التحقق من إعدادات URL و API Key
- التأكد من وجود اتصال بالإنترنت
- التحقق من حالة مشروع Supabase

### أخطاء الحفظ
- التأكد من صحة البيانات المدخلة
- التحقق من الحقول المطلوبة (اسم المنتج، السعر)
- التأكد من عدم وجود باركود مكرر

### أخطاء الاسترجاع
- التحقق من صلاحيات المستخدم
- التأكد من وجود بيانات في الجداول
- التحقق من استعلامات البحث

## 📞 الدعم

### للأسئلة والمساعدة
1. تحقق من رسائل الكونسول للمزيد من التفاصيل
2. استخدم دالة `forceInitAssistantButtons()` لإعادة تهيئة الأزرار
3. تحقق من إعدادات Supabase في لوحة التحكم

### تحديث الإعدادات
```javascript
// تحديث بيانات الاتصال
window.SupabaseManager.supabaseUrl = 'NEW_URL';
window.SupabaseManager.supabaseKey = 'NEW_KEY';
await window.SupabaseManager.init();
```

## 🎯 الملاحظات الهامة

1. **استبدل القيم الافتراضية** في `supabase-config.js` ببيانات مشروعك الفعلية
2. **فعّل Row Level Security** في إعدادات المشروع
3. **استخدم متغيرات البيئة** للبيانات الحساسة في الإنتاج
4. **احتفظ بنسخة احتياطية** من البيانات بانتظام
5. **راقب استخدام المشروع** لتجنب تجاوز الحدود المجانية
