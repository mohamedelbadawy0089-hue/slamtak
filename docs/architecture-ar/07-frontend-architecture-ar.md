# 07 — هندسة الواجهات (Frontend Architecture)

> **يقابل:** «ثامنًا: هندسة الواجهات» كاملًا.
> **المرجع المصاحب:** `06-frontend-architecture.md`.

---

## 1. المبادئ الخمسة

1. **العربية أولًا (RTL-native)** — لا «ترجمة لاحقًا»: كل مكوّن يُبنى بخصائص CSS منطقية.
2. **الواجهة لا تحمي البيانات** — كل قرار أمني في الخادم؛ الواجهة تُخفي وتُرشد فقط.
3. **شاشة واحدة لكل مهمة** — أمين المخزن لا يرى قوائم المشتريات في تنقّله.
4. **البطء غير مقبول** — ميزانية أداء ملزمة أدناه.
5. **العمل على موبايل 360px أولًا** للعمليات الميدانية (مسح باركود، جرد).

## 3. هيكل الصفحة القياسي (Layout Contract)

```text
┌─────────────────────────────────────────────────────────────┐
│ Topbar: اسم المخزن · بحث عام (Ctrl+K) · إشعارات · حساب      │
├──────────┬──────────────────────────────────────────────────┤
│ Sidebar  │ PageHeader: العنوان · وصف · أزرار أساسية        │
│ (حسب     │ ─────────────────────────────────────────────── │
│ دور      │ FiltersBar (تاريخ/حالة/بحث)                      │
│ المستخدم)│ DataTable / Form / Detail                        │
│          │ Pagination + ملخص عددي                           │
└──────────┴──────────────────────────────────────────────────┘
```

**قواعد:** شريط جانبي مبني من الصلاحيات (لا من قائمة ثابتة)؛ صفحة التفاصيل تعرض «الملخص + التبويبات + السجل الزمني»؛ كل جدول له حالة فارغة وحالة تحميل (Skeleton) وحالة خطأ قابلة لإعادة المحاولة.

## 4. مكتبة المكونات (Design System)

| المستوى | المكونات |
|---|---|
| أساس | `Button, Input, Select, Combobox, Checkbox, Radio, Switch, Textarea, DatePicker, MoneyInput, QuantityInput` |
| تخطيط | `AppShell, Sidebar, PageHeader, Card, Tabs, Section, EmptyState, StatCard` |
| بيانات | `DataTable` (فرز/تصفية/تحديد/تصدير/حفظ العرض), `Pagination`, `VirtualList`, `BarcodeScannerInput`, `BatchPicker` |
| نماذج | `Form`, `FormField`, `FormError`, `FormActions`, `ConfirmDialog`, `DangerConfirm` (يتطلب كتابة السبب) |
| تغذية راجعة | `Toast`, `Alert`, `ErrorBanner`, `LoadingSkeleton`, `ProgressSteps` |
| نطاق | `ProductPicker`, `CustomerPicker`, `SupplierPicker`, `ExpiryBadge`, `StockBadge`, `PriceTag`, `PermissionGate` |

**قواعد المكونات:**
- كل مكوّن يعمل RTL وLTR، ويدعم `dir` من الجذر.
- لا ألوان/مسافات مكتوبة يدويًا: فقط tokens (`--color-danger`, `--space-4`).
- `PermissionGate` **للعرض فقط**، وكل عملياته تُتحقّق خادميًا.
- كل مكوّن Table يدعم لوحة المفاتيح بالكامل.

## 5. إدارة الحالة

| النوع | الأداة | مثال |
|---|---|---|
| حالة الخادم | TanStack Query | قوائم المنتجات، الأرصدة، الفواتير |
| حالة النموذج | react-hook-form + Zod | إنشاء فاتورة، تسوية |
| حالة الواجهة المحلية | `useState`/`useReducer` | فتح لوحة، تبويب |
| حالة عامة صغيرة | Zustand (اختياري، لحالة الجلسة/الواجهة فقط) | الشريط الجانبي، اللغة |
| **ممنوع** | تخزين بيانات مالية/مخزنية دائمة في المتصفح | لا `localStorage` لبيانات العمل |

**المفاتيح:** `['products', filters]`, `['balances', productId]`, `['movements', range]`. **الإبطال** بعد كل كتابة ناجحة لمفاتيح الوحدة المتأثرة فقط. `staleTime` 30 ثانية للقوائم، 0 للأرصدة.

**الجلسة:** كوكي `HttpOnly` فقط؛ `GET /api/v1/me` هو مصدر الحقيقة (المستخدم، المخزن، الصلاحيات، إعدادات). لا توكن في JS.

## 6. النماذج والتحقق ورسائل الخطأ

| القاعدة | التفصيل |
|---|---|
| مخطط واحد | `packages/contracts` (Zod) يُستخدم في الواجهة والخادم |
| تحقق فوري | عند `onBlur`، وبعد أول إرسال عند `onChange` |
| أرقام | `QuantityInput` بثلاث خانات عشرية، `MoneyInput` بمنزلتين، منع الفاصلة العربية في الإدخال |
| رسائل عربية | من خريطة `code → نص`، لا نص الخادم الخام |
| أخطاء الحقول | تحت الحقل + تركيز تلقائي على أول خطأ |
| أخطاء العملية | `ErrorBanner` أعلى النموذج مع `correlationId` وزر «إعادة المحاولة» عند الانطباق |
| منع الإرسال المزدوج | زر معطّل + Idempotency key يُولَّد مرة عند فتح النموذج ويُثبَّت حتى النجاح |
| فقدان البيانات | تحذير `beforeunload` عند وجود تغييرات غير محفوظة |

**رسائل مقترحة:** «الكمية أكبر من المتاح (7) في التشغيلات الصالحة» · «انتهت صلاحية هذه التشغيلة ولا يمكن صرفها» · «تغيّر السعر من 25.00 إلى 27.00 — أعد المراجعة» · «ليس لديك صلاحية اعتماد التسويات».

---

## 7. التنقل والصلاحيات في الواجهة

- التنقل يُشتق من مصفوفة `nav.ts` مع `permission` لكل عنصر؛ يُفلتر بـ `me.permissions`.
- إذا فتح المستخدم رابطًا بلا صلاحية → صفحة `403` بنص واضح وزر «العودة للوحة»، **لا** تحويل صامت.
- البحث العام (`Ctrl+K`) يبحث في الأقسام المسموحة فقط، والبحث في البيانات يمر بالـ API السياقي.
- «آخر ما زرته» و«إجراءات سريعة» حسب الدور (أمين المخزن: استلام/صرف؛ المحاسب: دفعات/تقارير).

## 8. حالات التحميل والفراغ والخطأ

| الحالة | التصميم |
|---|---|
| تحميل أول | Skeleton بنفس تخطيط الجدول (لا Spinner صفحة كاملة) |
| تحميل جزئي | مؤشر في رأس الجدول + تعطيل الفرز |
| فراغ أولي | رسم توضيحي + سبب + زر إجراء أساسي («أضف أول منتج») |
| فراغ بعد تصفية | «لا نتائج لهذه الفلاتر» + زر «إزالة الفلاتر» |
| خطأ شبكة | بطاقة خطأ + زر إعادة المحاولة + `correlationId` |
| خطأ صلاحية | 403 واضح مع طلب الوصول من المدير |
| PWA بلا اتصال | شريط «أنت دون اتصال — القراءة فقط» + منع الحفظ |

## 9. RTL والتوطين

| البند | القرار |
|---|---|
| الاتجاه | `<html lang="ar" dir="rtl">`، خصائص منطقية `ms/me/ps/pe/start/end` |
| الأرقام | لاتينية في الجداول والحقول المالية، عربية في النصوص السردية |
| التواريخ | `ar-EG` عرضًا، `ISO` نقلًا |
| العملة | `ج.م` بعد الرقم، `EGP` في الـ API |
| الخطوط | IBM Plex Sans Arabic (وزن 400/600/700) + fallback نظام |
| تبديل اللغة | `next-intl` + `locale` في المسار `/en/...` مستقبلًا؛ النصوص من ملفات لا من كود |
| الأيقونات | `lucide-react`؛ لا أيقونات نصية |
| الطباعة | قالب فاتورة A5/A4 RTL بخط مضمّن (توليد PDF خادميًا) |

## 10. إمكانية الوصول (WCAG 2.1 AA)

- تباين ≥ 4.5:1 للنص، ≥ 3:1 للعناصر الكبيرة.
- تركيز مرئي واضح على كل عنصر تفاعلي، وترتيب `Tab` منطقي.
- كل حقل له `label` مرتبط، وكل رسالة خطأ مرتبطة بـ `aria-describedby`.
- `role="status"` للتنبيهات اللحظية، `aria-live="polite"` للإشعارات.
- الجداول: `th scope`, وصف للجدول، وليس الاعتماد على اللون وحده (صلاحية قريبة: أيقونة + نص).
- الأهداف اللمسية ≥ 44×44px.
- تشغيل كامل بلا ماوس: بيع، استلام، بحث، تنقّل جداول.
- اختبار آلي: `@axe-core/playwright` يفشل عند أي انتهاك حرج.

## 11. PWA والموبايل

| القدرة | التفصيل |
|---|---|
| التثبيت | Manifest + أيقونات + `display: standalone` |
| العمل بلا اتصال | **قراءة فقط** لآخر الصفحات المزارة؛ **ممنوع** حفظ بيع/تسوية محليًا (خطر تلاعب وازدواج) |
| المسح | `BarcodeScannerInput` عبر كاميرا + قارئ USB (إدخال لوحة مفاتيح) |
| التحديثات | `Serwist` مع إشعار «إصدار جديد — تحديث» لا تحديث قسري أثناء العمل |
| الأداء | TTI < 3s على 4G متوسط، حجم JS أولي < 200KB مضغوط |
| الطباعة من الموبايل | PDF خادمي يُعرض/يُشارك، لا طباعة CSS مباشرة على الهاتف |
