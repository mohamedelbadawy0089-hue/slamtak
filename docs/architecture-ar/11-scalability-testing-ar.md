## 2. الفهرسة والاستعلامات

| القاعدة | التفصيل |
|---|---|
| ترتيب الفهرس | يبدأ بـ `tenant_id` ثم عمود الانتقائية الأعلى |
| فهارس جزئية | للصفوف النشطة فقط (`WHERE status='active'`) |
| فهارس تغطية | `INCLUDE` لتجنّب Heap Fetch |
| ممنوع | فهرس على عمود منخفض الانتقائية منفردًا (boolean) |
| `EXPLAIN` إلزامي | أي استعلام جديد على جدول > 1M صف |
| ممنوع N+1 | تحميل العلاقات بـ `IN`/`JOIN` دفعة واحدة |
| ممنوع `SELECT *` | أعمدة محددة فقط |
| التجميعات | `materialized view` للتقارير الثقيلة مع `REFRESH CONCURRENTLY` |
| النوافذ | `LIMIT/OFFSET` ممنوع للصفحات العميقة — Cursor فقط |
| النص العربي | `pg_trgm` + `unaccent` + `tsvector` بأعمدة مولّدة |

**ميزانية أداء (SLO):** قراءة قائمة p95 ≤ 250ms، تفاصيل ≤ 150ms، إنشاء فاتورة بيع ≤ 1.2s (5 أصناف)، تقرير قياسي ≤ 3s، تصدير 50K صف ≤ 90s في طابور.

---

## 3. التخزين المؤقت (Caching)

| الطبقة | ماذا | TTL | الإبطال |
|---|---|---|---|
| HTTP/CDN | أصول ثابتة، صفحات عامة | سنة/ساعة | بناء جديد |
| TanStack Query | قوائم، منتجات، عملاء | 30s | بعد كل كتابة (invalidate keys) |
| ذاكرة الـ API | صلاحيات المستخدم، إعدادات المستأجر | 60s | `token_version`/نشر |
| Materialized Views | تقارير، قيمة المخزون | 5–60 دقيقة | `REFRESH CONCURRENTLY` مجدول |
| Redis | غير مستخدم في الملف A | — | — |

**قاعدة:** لا كاش لبيانات مالية حسّاسة بقرار لحظي (الأرصدة تُقرأ من القاعدة عند البيع).

---

## 4. تجميع الاتصالات

- كل اتصال API يفتح معاملة قصيرة؛ لا اتصال دائم من Edge.
- المجمّع في **وضع المعاملة** ⇒ ممنوع `SET` دائم؛ `SET LOCAL` فقط داخل المعاملة (ADR-009).
- أقصى اتصالات التطبيق = `pool_size × instances`، ويُضبط تحت حد المزود.
- `statement_timeout=5s`, `lock_timeout=2s`, `idle_in_transaction=10s` مفروضة على الدور.

## 5. المهام الخلفية والتوسع الأفقي

| المهمة | التكرار | التوسع |
|---|---|---|
| تنبيهات الصلاحية/المخزون | يوميًا 06:00 | تقسيم بالمستأجر (دفعات 50) |
| فحوص السلامة | كل ساعة/يوميًا | قراءة فقط، بلا قفل طويل |
| تقارير ثقيلة/تصدير | عند الطلب | طابور + `FOR UPDATE SKIP LOCKED` |
| إنشاء أقسام | أسبوعيًا | مهمة واحدة |
| تنظيف مفاتيح/رموز | يوميًا | صف واحد لكل نوع |

**آلية العامل الآمنة:** `SELECT ... FROM app.jobs WHERE status='pending' AND run_after<=now() ORDER BY run_after LIMIT 20 FOR UPDATE SKIP LOCKED` ثم `locked_by` + `locked_until`. عاملان لا يلتقيان على مهمة أبدًا.

**التوسع الأفقي:** الـ API بلا حالة (Stateless) — الجلسة في القاعدة/التوكن، والملفات في R2، والكاش داخل الطلب. أي نسخة إضافية تعمل فورًا بلا تنسيق.

## 6. نقاط التحوّل (Trigger Points)

| المؤشر | العتبة | الإجراء |
|---|---|---|
| استدعاءات Edge شهريًا | > 300K | ترقية أو انتقال للملف B |
| زمن p95 لقراءة | > 400ms مستمر | مراجعة فهارس/كاش |
| حجم `inventory_movements` | > 20M | أرشفة أقسام قديمة + تقسيم أدق |
| اتصالات القاعدة | > 70% من الحد | مراجعة المجمّع/تقصير المعاملات |
| مهام متأخرة | > 1000 | عامل إضافي/تقسيم |
| تقرير > 10s | متكرر | View مادي أو خدمة تقارير |

## الجزء الثاني — استراتيجية الاختبارات

## 7. هرم الاختبارات والأدوات

| المستوى | الأداة | النسبة المستهدفة | مدة |
|---|---|---|---|
| وحدة (Domain/Use Case) | Vitest | 60% | ثوانٍ |
| تكامل (API + PG حقيقي) | Vitest + Testcontainers | 25% | دقائق |
| قاعدة بيانات (RLS/قيود/Triggers) | pgTAP | 8% | دقائق |
| عقد (OpenAPI) | اختبار مخطط | 3% | ثوانٍ |
| E2E | Playwright | 3% | دقائق |
| أمن/حمل | k6 + ZAP(يدوي) | 1% | ساعات |

**التغطية:** ≥ 80% للـ `domain` و`application`، ≥ 60% إجمالًا. **لا** تغطية وهمية باختبارات بلا assertions.

**بيانات الاختبار:** مستأجران (A وB) بمنتجات/تشغيلات/أسعار متشابهة عمدًا — لاكتشاف أي تسريب. كل اختبار تكامل يبدأ بقاعدة نظيفة (migrations + seed).

## 8. مصفوفة الاختبارات العشرة الإلزامية

| # | المتطلب | الاختبار | النجاح يعني |
|---|---|---|---|
| 1 | لا وصول لبيانات مخزن آخر | مستأجر B يستدعي كل GET لمعرّفات A | 404 لكل مورد، وصفر صفوف مسربة |
| 2 | لا اختلاط كتالوجات | منتجات متشابهة (نفس الباركود) في A وB | كل مخزن يرى منتجه فقط؛ `UNIQUE(tenant_id,barcode)` يعمل |
| 3 | لا اختلاط أرصدة | رصيد A=100، B=10 | تقارير وبيع كل منهما مستقل |
| 4 | لا اختلاط أسعار | نفس المنتج بسعرين | فاتورة A بالسعر A فقط |
| 5 | لا اختلاط تشغيلات | نفس `batch_no` في A وB | FEFO يستخدم تشغيلات مخزنه فقط |
| 6 | لا اختلاط موظفين | موظف A يحاول إدارة فريق B | 404/403 + تدقيق |
| 7 | سلامة الشراء/البيع/المرتجع | دورة كاملة: شراء 100 → بيع 30 → مرتجع 5 → إتلاف 2 | رصيد 73، دفتر يطابق، مبالغ صحيحة |
| 8 | دقة الأرصدة تحت التزامن | 50 طلبًا متوازيًا على 10 وحدات | 10 نجاح، 40 رفض، لا سالب |
| 9 | منع تكرار الحركات | نفس `Idempotency-Key` 10 مرات | حركة واحدة، نفس الاستجابة |
| 10 | استعادة من النسخة | استعادة إلى قاعدة جديدة + مقارنة checksums | تطابق 100% للجداول الحرجة |

**اختبار الحارس (Mutation Test):** في CI، يُعطَّل RLS عمدًا على جدول واحد ويجب أن **تفشل** اختبارات العزل. إن نجحت، فالاختبارات لا تحمي فعلًا. يُنفَّذ شهريًا لا في كل بناء (لتوفير الوقت).

## 9. باقي مستويات الاختبار

| النوع | ما يُغطّى | متى |
|---|---|---|
| Unit | FEFO، التسعير، الخصومات، الضريبة، صلاحية الحالة | كل commit |
| Integration | كل Use Case على PG حقيقي، معاملات، Triggers | كل PR |
| Database | RLS، قيود، منع الحذف، منع تغيير `tenant_id`، الأقسام | كل PR |
| API Contract | كل مسار: 200/201/4xx، الغلاف، الأخطاء، الترقيم | كل PR |
| Security | A1–A12، P1–P10، حقن، XSS، CSRF، Rate limit | كل PR (مختصر) + أسبوعيًا (كامل) |
| Performance | استعلامات حرجة مقابل بيانات 1M صف | أسبوعيًا |
| Load | 200 VU 10 دقائق، 500 VU ذروة | قبل كل إصدار |
| E2E | دخول → إضافة منتج → استلام → بيع → تقرير | قبل كل إصدار |
| Regression | كل ما سبق آليًا | كل PR (مجموعة مختارة) |
| Backup Restore | استعادة كاملة + انتقائية | شهريًا + قبل أول عميل |
| Accessibility | axe على 6 شاشات | كل PR |
| PDF/طباعة | صحة العربية في A4/A5 | كل إصدار |

## 10. بوابات CI (لا نشر بلا نجاح)

| البوابة | الشرط |
|---|---|
| Typecheck | صفر أخطاء (`tsc --noEmit`) |
| Lint/Arch | ESLint + dependency-cruiser + فحص "لا localStorage" + "كل route له permission" |
| Docs (AR) | `npm run check:docs-ar` — نطاق الفحص في `scripts/check-architecture-ar-docs.mjs` |
| Unit + Integration | كلها خضراء |
| DB/RLS | pgTAP أخضر + اختبارات A1–A12 |
| Contract | `openapi.yaml` محدّث ومطابق |
| Build | بناء الويب والـ API ناجح |
| E2E | السيناريو الذهبي أخضر |
| Security scan | `npm run check:secrets` (secret-guard) أخضر: لا `.dev.vars`/`.env` متتبَّع؛ وgitleaks لسجل Git لم يُضف بعد |
| Performance smoke | لا انحدار > 20% في زمن استعلامات مرجعية |
